# Contributing

Thanks for your interest in contributing to this project! Contributions are welcome — feel free to open an issue to discuss a bug or feature, or submit a pull request directly. When contributing, please keep changes focused, write clear commit messages, and add a brief description of what your PR does and why. For any substantial changes, it's a good idea to open an issue first to coordinate. All contributors are expected to follow the project's code of conduct (be respectful, constructive, and inclusive). Happy hacking!
